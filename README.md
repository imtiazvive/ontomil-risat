# অন্তমিল প্রকাশনী

বইয়ের বিভাগ, অনুসন্ধান, শপিং ব্যাগ ও হোয়াটসঅ্যাপে অর্ডারসহ Next.js-এ তৈরি
একটি বইয়ের দোকান।

## স্থানীয়ভাবে চালান

১. `.env.example` ফাইলটি কপি করে `.env.local` নামে রাখুন।
২. `NEXT_PUBLIC_WHATSAPP_NUMBER`-এ বিক্রেতার আন্তর্জাতিক ফোন নম্বরটি শুধু
   সংখ্যা দিয়ে লিখুন (যেমন, `8801XXXXXXXXX`)।
৩. `npm run dev` চালিয়ে [http://localhost:3000](http://localhost:3000) খুলুন।

বইয়ের নাম ও দাম `app/page.js`-এ নমুনা হিসেবে দেওয়া হয়েছে; আপনার দোকানের
বইয়ের তালিকা অনুযায়ী সেগুলো পরিবর্তন করুন।

বইয়ের প্রচ্ছদ বা নাম থেকে ৫ পৃষ্ঠার নমুনা পাঠ খুলুন। বর্তমান পাঠ্যটি
প্রদর্শনের জন্য লেখা নমুনা; প্রকৃত বইয়ের অংশ বা PDF যোগ করার আগে ব্যবহারের
অনুমতি নিশ্চিত করুন।
